# POS Suite Serveur (canal de test)

Canal de test de POS Suite Serveur : versions suffixées -test, reliées au service en ligne de staging.
Ne pas installer en boutique : utilisez le canal stable https://github.com/IsmaelRAJAOMANIRY/pos-suite-desktop.

Vérifier les fichiers : `sha256sum -c SHA256SUMS` (signature GPG : `gpg --verify SHA256SUMS.asc`).
